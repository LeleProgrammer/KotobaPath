# KotobaPath · 言葉の道 1.7.0

中文讲解的离线日语学习工具。纯HTML、CSS、原生JavaScript，无ES Module、构建或CDN依赖；默认深色，正文字号18～24px。不含口语、听力和音频。

## 个人学习功能

词汇页可单条或整页加入单词本。单词本按等级、掌握、到期、收藏或已练单词筛选，支持批量选择、复习、闪卡、读音输入和TSV导出。收藏与笔记仍有独立入口，旧收藏直接可见；可从收藏标签加入单词本。

错题本可按级别、内容、关键词与次数／时间排序，查看原题、上次答案和解析，逐条重练或移出。答对自动移出当前错题，但保留历史与复习计划。历史回看限最近5000次记录。旧存档的错题没有原题快照时，继续按知识点生成题目。

汉字上方默认显示平假名，词条、例句与阅读正文均可使用；可在设置、词汇页、单词本和阅读页关闭，偏好随存档保存。读音题和闪卡正面暂时隐藏，避免提示答案。句子读音为离线词法分析加规则，不等于全部教师逐词审校；未知词不强行注音，个别专名和多音字可对照词卡核实。网站运行不需要分词软件或网络请求。

## 启动与升级

1. 先完整解压，再运行，不要在压缩包内双击启动器。
2. 可直接打开 `index.html`。所有学习内容通过本地普通script加载，无fetch依赖。
3. 推荐固定地址启动：Windows安装Python3.8+后双击`start.bat`；macOS/Linux运行`python3 start.py`。浏览器自动打开 `http://127.0.0.1:8765/`。启动器仅提供静态文件，无学习数据后端。
4. 更新前关闭旧启动窗口；新版保留1.0.1的CSS／JS MIME类型与缓存修复。若仍是旧页面，按Ctrl+F5。
5. 日语输入题使用系统日语输入法。输入法选词过程中不会误触发Enter交卷。

地址、端口与存档键保持不变。**同一浏览器、同一地址的旧进度自动继承**，升级前自动保留一份原始JSON。主动导出备份仍是好习惯。

`file://`、`localhost`、`127.0.0.1`、不同端口和浏览器属于不同存储环境。迁移时从原环境导出，在新版导入。

## 存档兼容与同步

支持1.0／1.0.1／1.2／1.3／1.4／1.4.1旧JSON。旧ID、课文完成、掌握、错题、收藏、笔记、草稿、复习日程与统计保留；新增内容不会自动标记掌握。

设置页导入默认“合并进度”：保留两边独有条目；有修改时间则择较新状态；文本不同保留冲突副本供整理。重复导入新版存档不会重复累计作答。

这是**通过JSON手动跨设备同步**，没有账号或自动云同步。旧版日累计缺少事件ID，合并按日取两边较大值，无法精确还原两台旧设备同日独立作答之和。1.2后的作答按唯一事件ID合并去重。规则、限制和后续开发约束见 `SAVE_COMPATIBILITY.md`。

## 学习功能

- 入门、N5～N1自由分级路线；词汇、语法、汉字搜索和筛选。
- 新“辨析与专题”：接续、视点、证据、立场、让步、责任和语域的成对比较。
- 五十音、平片假名、浊半浊音、拗音与外来音。
- 活用工坊：五段、一段、サ变、カ变17种形式；名词、い形容词、な形容词活用。
- 15个训练入口：词义、读音、词形、句型、接续、填空、排序、翻译重构、活用、汉字、假名、闪卡、人工语境辨析、综合、限时综合。
- 分级阅读、通知与邮件整合、多文本比较、800余字的N1长篇；逐题解析和中文内容对照。
- 每道新阅读理解题分别安排复习；旧版篇级复习记录继续可用。
- 写作任务、写作路径、短段落示范、草稿自动保存、字数与形式自检、TXT导出。
- 间隔复习、错题再练、收藏、笔记、学习目标和统计。

“课文读完”和“知识掌握”分别记录；掌握是自评，不是能力证书。自由作文不会进行不可靠的语义自动评分；翻译重构只核对预设标准句。限时综合不是官方JLPT等值模拟卷。

1.2.0加入的60道句子语境题也用于60道输入填空，属于同素材的两种训练方式，不重复计算为不同知识点。自动组题数量不等于内容量。

node tests/expansion14.cjs

生成器不重新编号。完整开发与兼容约束见 `DEVELOPMENT.md` 和 `SAVE_COMPATIBILITY.md`，验证记录见 `QA.md`。
