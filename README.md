# KotobaPath · 言葉の道

面向中文学习者的离线日语学习网站。纯 HTML + CSS + 原生 JavaScript，无构建、无 npm、无 ES Module、无 CDN、无账号与后端依赖。默认深色，大字号；不含听力、口语或音频功能。未发布到 Site。

## 先说明交付范围

这是功能完整、课程内容仍需扩充的学习工具，**不是已经穷尽 N5～N1 知识的完整教材**。不要把“292项基础／语法课读完”当作从零达到 N1 的认证。现在的语法深度、阅读数量、综合训练强度还不足以独立完成这个目标。具体缺口见 `CONTENT_COVERAGE.md`，没有以占位条目或模板复制冒充完整课程。

JLPT 未公布现行考试的完整词汇、汉字和语法清单，本站等级是第三方／自行编排的学习参考。未包含听力，也不能据此保证通过含听力的 N1 考试。自动组题数量不等于知识点数量。

## 启动

1. **先解压整个压缩包**，进入 `KotobaPath` 文件夹。
2. 用现代 Chrome、Edge、Firefox 或 Safari 打开 `index.html` 即可开始。所有数据通过本地传统 script 加载，没有 fetch 或模块跨域依赖。
3. 若浏览器限制本地文件存档，推荐固定地址启动：装有 Python 3.8+ 的 Windows 双击 `start.bat`；macOS/Linux 运行 `python3 start.py`。自动打开 `http://127.0.0.1:8765/`。Python只提供静态文件，不处理学习数据。
4. 日语打字题请打开系统日语输入法。以汉字和假名作为目标输入，读音题兼容片假名；不是罗马字转日语输入法。

网站实际运行不需要 Python，也不需要联网。可选启动器只为稳定本地地址与浏览器存储。在线外部链接仅为资料来源，点击后才访问。

## 功能

- 入门 → N5 → N1 学习路线，所有课程可自由访问。
- 词汇／语法／汉字全文检索、分级过滤、分页、收藏、掌握标记与笔记。
- 平片假名、浊音半浊音、拗音和外来音表；识读测验。
- 活用工坊：五段、一段、サ变、カ变；17种动词形式及形容词／名词活用；来る读音提示；いい的特殊变化。
- 14个训练入口：词义选择、读音输入、词形识别、句型理解、接续辨析、填空、句子排序、翻译重构、活用输入、汉字读音、假名识读、闪卡、综合、限时综合。
- 另有分级阅读理解、信息检索、多文本比较和自由写作。
- 即时解析、组后报告、错题再练、简化间隔复习、学习目标和统计。
- 自动本地保存；JSON导入预览、校验、备份与替换；异常存档保护；多标签页冲突提示。
- 写作自动存稿、导出TXT、字数与目标表达形式自检。不会以字数或关键词匹配伪装语言能力评分。
- 18～24px正文字号、亮暗主题、响应式布局、键盘答题与输入法组合保护。

## 推荐使用顺序

1. 阅读入门16课，在假名实验室练识读；在纸上练写字形。
2. 选择N5路线，每天学少量语法，同时学10～20个词；看词形、假名、词性和例句，不只记译词。
3. 学完动词分类后交替练て形、ない形、た形，再学可能／被动／使役。错题回到讲解查明原因。
4. 每天先做到期复习；新词与语法混合练。熟悉卡片可以手动标记掌握，读完课文则单独标记完成。
5. 每级练阅读和写作，自由写作按清单校订。参考短段落只示意结构，并非按任务字数完成的整篇范文。
6. 逐级扩展到N1，并结合更多可靠教材、真实文章和独立测验。本站不能替代充分的长期输入与能力验证。

## 存档注意

- 存储键：`kotobapath.save.v1`。浏览器隐私模式、清除站点数据、改变地址或端口都可能影响存档。
- `file://` 与 `http://127.0.0.1:8765` 是不同来源，互不自动共享。搬文件夹／换电脑／改部署地址前先导出JSON，然后导入。
- 错题答对会移出当前错题列表，历史记录仍在。每次答题都调整复习日程；掌握标记是独立自评。
- 闪卡按本人自评分配日程；简化算法不是FSRS，不能宣称最佳记忆效率。
- 记录历史只保留最近5000次供逐条查看；按日累计统计持续保留。
- 导入会生成当前备份下载，确认浏览器未阻止下载。异源存档只能手动迁移，无跨设备自动同步。
- 任何页面都可用右上角导出，设置页可导入；重置前需输入RESET并提供备份下载。

## 修改与验证

直接编辑源码即可，不必编译。`data/*.js` 是可读的数据文件，格式见 `DEVELOPMENT.md`。保留条目ID才能兼容已有存档。

安装Node.js后可选运行：

```sh
node tests/check.cjs
```

测试覆盖活用、各级组题、数据ID、SRS、存档校验与转义等。它不是语言学或课程充分性的认证。浏览器人工检查范围见 `QA.md`。
